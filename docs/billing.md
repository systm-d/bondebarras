# Billing and GitHub limits

What the Billing tab reads and what it never modifies: GitHub Actions minutes
against the allowance of the organization's plan, Actions storage in GB-hours,
the distinction between artifacts, Packages and cache storage, the default
included cache threshold of 10 GB per repository, the configured limit that no
endpoint exposes, what is shown when the plan cannot be read, Enterprise
organizations and shared quotas, Actions budgets, artifact and log retention,
and the validity dates of every figure quoted.

bullet in the README](../README.md#features) carries the detail, and
