# Installation

How to install bondebarras on each platform it supports, and how to keep it
up to date. This page will cover the current release status (pre-release or
stable), a platform / architecture / format / availability table using
explicit states rather than checkmarks, SHA-256 verification of a downloaded
asset, the per-platform steps for Linux, Debian/Ubuntu, Fedora/RHEL, macOS
Apple Silicon and Windows x86-64, building from source, the channels that are
not published yet, uninstalling, and updating with `bondebarras update`.
